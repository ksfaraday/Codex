# Filter Studio

한국어 인터페이스의 RF 필터 합성 웹 앱. LC, 마이크로스트립, 직사각형 도파관의 초기 설계를 지원합니다. Dassault Systèmes / CST의 제품이 아닌 독립적인 구현입니다.

## Windows 바로 실행 (설치 불필요)

**[Windows용 ZIP 다운로드](https://github.com/ksfaraday/Codex/raw/refs/heads/main/releases/Filter-Studio-Windows.zip)**

1. 위 링크로 ZIP을 내려받습니다. GitHub 로그인이 필요할 수 있습니다.
2. ZIP을 오른쪽 클릭하고 **모두 압축 풀기**를 선택합니다.
3. `Filter-Studio.html`을 Edge 또는 Chrome으로 엽니다.

Node.js나 Bash는 필요 없습니다. 파일 링크가 미리보기 화면으로 열리면 **Download raw file** 버튼으로 저장하세요.

## 실행

Node.js 20 이상. 외부 런타임 패키지와 설치 과정이 필요 없습니다.

```sh
cd /workspace/Codex
npm start
```

기본 포트는 3000이며 `PORT=8080 npm start`로 변경할 수 있습니다. 계산은 브라우저에서 수행하며 입력 사양을 서버에 보내지 않습니다. 서버는 네 개의 정적 앱 파일만 제공합니다.

```sh
npm test
npm run check
```

## Windows에서 설치 없이 실행

배포된 ZIP을 마우스 오른쪽 버튼으로 클릭해 **모두 압축 풀기**한 뒤, `Filter-Studio.html`을 Edge 또는 Chrome으로 여세요. Node.js, Bash, 서버, 인터넷 연결은 필요하지 않습니다. 브라우저의 파일 다운로드 기능으로 프로젝트와 설계 파일을 저장합니다.

개발자가 단일 HTML 배포본을 다시 만들려면 `npm run build:portable`을 실행하세요. `dist/Filter-Studio.html`에 CSS와 계산 엔진이 모두 포함됩니다. 관리되는 회사 PC에서는 로컬 HTML 실행 또는 다운로드 정책이 적용될 수 있습니다.

## 사용

1. LC / Microstrip / Waveguide 구현 방식을 선택합니다.
2. 응답, Butterworth 또는 Chebyshev I 근사 함수, 차수(1–12), 주파수와 임피던스를 설정합니다.
3. **합성 및 분석**을 누릅니다. 주파수 응답, 군지연, 회로 또는 배치도와 설계 표가 갱신됩니다. 그래프 위 포인터로 수치를 확인할 수 있습니다.
4. 프로젝트 JSON을 저장하고 다시 불러올 수 있습니다. 설계 표 CSV, 회로/평면도 SVG 및 Touchstone 2.0 S-파라미터 파일을 내보낼 수 있습니다. 내보내기는 현재 입력값을 다시 검증·계산합니다.

주파수는 GHz, 물리 치수는 mm입니다. 대역통과/대역저지의 주파수는 **기하 중심**이고 대역폭은 상·하한 주파수의 차이입니다. 하한과 상한은 `sqrt(f0² + BW²/4) ∓ BW/2`입니다.

## 지원 모델과 한계

### LC

- 저역통과, 고역통과, 대역통과, 대역저지.
- 정규화된 Butterworth / Chebyshev I ladder 원형을 물리 L/C로 변환합니다.
- 직렬 소자로 시작하는 ladder이며 band 변환에 따라 직렬/병렬 공진기로 변환합니다.
- ABCD 행렬로 응답을 계산하고 전력 정규화된 S-파라미터를 구합니다.
- 짝수 차수 Chebyshev의 부하는 `Rsource × g[n+1]`입니다. 양 포트 50 Ω에 맞춘 추가 매칭은 포함하지 않으며 실제 종단을 화면과 Touchstone 2.0에 기록합니다.
- 이상적 무손실 소자입니다. Q, ESR, 기생, 자기 공진, 공차 모델은 포함하지 않습니다.

### 마이크로스트립

- 100 Ω / 25 Ω stepped-impedance **저역통과**.
- 준정적 유효 유전율과 임피던스 식을 역산해 폭을 구합니다. 선로 길이는 짧은 선로 근사로 초기 합성합니다.
- 응답은 합성 원형을 그대로 그리는 대신 각 전송선의 ABCD 행렬로 재계산합니다. 따라서 원형의 차단 응답과 차이가 나며, 특히 큰 전기 길이에서는 재조정이 필요합니다.
- 도체 두께 0, 손실·분산·단차 기생·상호 결합을 제외한 모델입니다.
- 평면도는 연결 순서와 치수를 보여 주는 **비축척 개념도**입니다. 제조용 Gerber나 EM mesh가 아닙니다.
- 결합 선로/헤어핀/인터디지털 대역통과 필터는 현재 지원하지 않습니다.

### 도파관

- 공기 충전 직사각형 도파관 TE10, 결합 공진기 **대역통과**.
- WR-90 / WR-75 프리셋과 사용자 정의 a, b 치수.
- 통과대역이 TE10 차단 이상 및 TE20/TE01 차단 이하인지 검증합니다.
- `λg/2`의 비결합 공진기 초기 길이, 양단 외부 Q, 인접 공진기 결합계수를 합성합니다.
- **그래프는 LC 등가회로로 계산한 이상 목표 응답이며 도파관 전자기장 해석 결과가 아닙니다.**
- 아이리스 개구 치수, 결합에 의한 공진기 길이 보정, 유한 전도도 손실, 고차 모드, 실제 EM 필드 및 제작 도면은 포함하지 않습니다. 표시된 아이리스는 위치 표시용입니다. 실제 도파관 제작에는 별도의 EM 추출·최적화가 필요합니다.

## 계산 및 내보내기

- 801개의 선형 주파수 샘플; LC/도파관 모델은 이상적 ABCD 계산, 마이크로스트립은 무손실 전송선 ABCD 계산.
- 군지연은 S21 위상을 unwrap한 뒤 주파수에 대해 중앙 차분합니다. 깊은 영점 부근의 위상·군지연은 해석에 주의해야 합니다.
- 표시용 dB 하한은 −240 dB, 그래프 범위는 −100–0 dB입니다.
- Touchstone 2.0은 복소 RI, GHz, 포트별 기준 임피던스와 reciprocal S12/S21, S22를 기록합니다. 1.x만 지원하는 툴에서는 파일 변환이 필요할 수 있습니다.
- 프로젝트 JSON은 사양만 보관합니다. 로컬 파일을 다시 불러올 때 크기·형식·수치 검증을 수행합니다.

## 검증

`npm test`는 다음을 검사합니다.

- 네 가지 주파수 변환의 Butterworth 전달함수와 해석식 비교(1, 2, 5, 8, 12차).
- 짝수/홀수 차수 Chebyshev 전달함수와 해석식 비교.
- 세 구현 방식의 무손실 전력 보존, 공진점의 유한한 수치 처리.
- 선로 폭·길이, WR-90 차단 주파수·도파 파장·대칭 결합.
- 잘못된 사양, 차단/다중모드 영역 거부.
- Touchstone 포트 기준, 샘플 수, reciprocity 및 전력 보존.

Chromium에서 세 구현 방식, 네 가지 LC 응답, 군지연 전환, 도파관 프리셋/오류, 네 가지 다운로드, 프로젝트 저장/불러오기, 잘못된 JSON, 390px 모바일 레이아웃을 별도로 스모크 테스트했습니다. 실제 제작품이나 CST EM 결과와의 교차 검증은 수행하지 않았습니다.
